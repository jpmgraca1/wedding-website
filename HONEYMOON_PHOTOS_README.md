# Instruções para Adicionar Fotos da Lua de Mel

## ?? Fotos Necessárias

Adicione duas fotos na pasta `WeddingSite\wwwroot\pics-honeymoon\`:

1. **japan.jpg** - Uma foto representativa do Japão
2. **indonesia.jpg** - Uma foto representativa da Indonésia

## ?? Requisitos das Fotos

- **Formato:** JPG ou PNG
- **Orientação:** Horizontal (landscape) preferível
- **Tamanho recomendado:** Largura mínima de 800px
- **Qualidade:** Boa resolução mas não muito pesada (máx 2MB por foto)

## ?? Dicas de Fotos

### Japão ????
- Shibuya crossing, Tóquio
- Monte Fuji

- Shinkansen (comboio-bala)

### Indonésia ????

```

??? japan.jpg

```
